# InfoDaily Bot — Курсы валют и Погода в Telegram

Telegram-бот для отслеживания курсов валют и погоды с поддержкой платной подписки через **Telegram Stars**.

## Функционал
- Выбор отслеживаемых валют (USD, EUR, RUB, KZT и др.)
- Выбор городов для мониторинга погоды
- **Бесплатный тариф:** До 3 валют и до 2 городов
- **Premium-тариф:** Неограниченный выбор за 100 Telegram Stars (`XTR`)

## Технологический стек
- **Язык:** Python 3.10+
- **Фреймворк:** Aiogram 3.x
- **База данных:** SQLite3
- **Платежная система:** Telegram Stars Invoice API
